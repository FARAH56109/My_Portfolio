Project 02 — Asteroid Data Automation
Data Engineering · DEPI

Project Sentinel: NASA Asteroid Data Pipeline

A lightweight Python pipeline that retrieves near-Earth asteroid data from NASA's API, extracts selected attributes, and exports structured datasets for further analysis.

API INTEGRATION · 01

Retrieved asteroid records from the NASA Near Earth Object API.

DATA EXTRACTION · 02

Selected asteroid identifiers, names, magnitudes, estimated diameters, and hazard flags.

STRUCTURED OUTPUT · 03

Saved raw responses as JSON and processed records as CSV through a reusable Python pipeline.
